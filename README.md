# Pookie

Нативный клиент SoundCloud на .NET 10 и MewUI. Вход и браузерные запросы выполняет
отдельный процесс Electron.NET / Chromium на Linux, Windows и macOS.

Главная открывается с «Твоей волной»: непрерывным потоком музыки в режимах
«Баланс», «Любимое» и «Открытия». Волна использует лайки, историю, похожие треки,
миксы SoundCloud и релизы подписок; учитывает фактическое время прослушивания,
повторы и ранние пропуски. «Не моё» исключает композицию и распознанные версии.
Реакции перестраивают будущие рекомендации, сохраняя текущий трек и ручную очередь.
Профиль и режим хранятся локально для каждого аккаунта в `Wave/`; токены в профиль
не записываются. Это первая версия с локальным ранжированием, без обученной общей модели.
Настройки открываются в боковой панели у правого края всей контентной области,
за пределами отступов главной и карточки волны. Она подстраивается под
доступную высоту и ширину, а её содержимое прокручивается отдельно от страницы.
Палитра волны плавно меняется между режимами, включая переключения на паузе.
Ниже — карточки лайков и истории с обложками, открытия и свежие релизы подписок. Секции загружаются независимо;
результаты сохраняются в памяти на 10 минут и обновляются при следующем открытии
после истечения этого времени.
Кнопка воспроизведения на карточке запускает музыку, нажатие на карточку открывает
страницу трека или плейлиста.

В `src` три проекта: `Pookie.App` — приложение, `Pookie.Browser.Electron` —
браузерный процесс, `Pookie.SoundCloud` — клиент SoundCloud и общие модели
протокола для обоих процессов. Аудио, лирика, Discord, логирование и системные
медиакнопки находятся в папках приложения и собираются в его сборку.

```bash
dotnet build src/Pookie.App -p:PookieInstallElectron=true
dotnet run --no-build --project src/Pookie.App
```

Для первой установки браузерного runtime нужны Node.js 22+ и npm. Последующие
обычные сборки используют установленный runtime; `dotnet build Pookie.slnx`
без установки собирает код и локальные проверки. Публикация с
`-p:PookieInstallElectron=true` включает браузерный процесс и Chromium в
`BrowserHost/`, без зависимости от системного WebKitGTK или WebView2.

Профиль Electron сохраняется в каталоге данных Pookie `Browser/Electron`.
Вход использует существующий профиль, выход из аккаунта очищает его после
завершения браузера. Профиль из ранее проверенного прототипа подходит приложению.
