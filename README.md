# Pookie

Для разработки нужен .NET 10 SDK. Node.js используется только для служебных
скриптов, их тестов и сборки нативного libVLC в CI; `dotnet build`, `dotnet run`
и `dotnet publish` его не вызывают.

На Linux перед первой сборкой скачайте архив `libvlc-linux-x64` из Actions
нужного коммита и распакуйте сам артефакт (архив `.tar.gz` и файл `.sha256`)
в `artifacts/libvlc-runtime/`. Утилита на C# проверит контрольную сумму,
установит библиотеки в локальный кэш и скопирует их в результат сборки:

```sh
dotnet run --project src/Pookie.App
```

Дальнейшие сборки используют кэш без сети. Подробности и переменные для своего
архива описаны в [инструкции libVLC](tools/libvlc-linux/README.md).

На Windows защищённое воспроизведение использует системный PlayReady:
Widevine не загружается, принятие его соглашения не требуется.

На Linux и macOS при первом запуске поверх загрузчика Pookie появляется матовая стеклянная
карточка с условиями Google Widevine. Логотип загрузки остаётся на месте;
после подтверждения карточка закрывается и продолжается подготовка модуля.
Перед показом карточки приложение получает актуальный пакет напрямую у Google
и читает соглашение из его `LICENSE`. После явного принятия устанавливает
этот же пакет в свои данные и продолжает запуск. Принятие сохраняется; при изменении условий потребуется
принять их заново. Принятый установленный модуль работает без повторной загрузки.
Устанавливать браузер не нужно.
Подробности установки, поддерживаемых платформ и отдельного лицензирования
Widevine — в [инструкции DRM](src/Pookie.App/Audio/Drm/README.md).
